⚠️ THINGS TO AVOID

  ❌ Broken demo
     → Test everything 3x before presentation

  ❌ Incomplete features
     → Ship 1 complete feature, not 5 half-features

  ❌ Slow startup
     → Make sure backend loads models quickly (<5 sec)

  ❌ Complex setup
     → One command to run: python app.py + npm run dev

  ❌ No problem → solution narrative
     → "Construction sites lose ₹10L to theft annually"

  ❌ Code dump without context
     → Show judges YOU understand the code

  ❌ Overselling
     → "Detects plates in fog and rain" ← unless you tested!
